XLR8 - Voice Robot

Solo developerVoice pipeline complete; drive system being tuned
▧
XLR8 - Voice RobotProject imagery

THE BUILD

A modular ROS 2 voice assistant with separate nodes for speech, intent, LLM reasoning and speech output, plus voice-commanded motion through micro-ROS.

ENGINEERING NOTES

  • Two-stage intent routing: a fast keyword pass, followed by a Cohere LLM fallback for ambiguous commands.
  • Speech output is a cancellable ROS 2 action, so the robot stops talking when interrupted.
  • A fixed action interface separates the assistant stack from robot control.
