THE BUILD

An educational engineering simulation: diagnose a surgical arm’s slow joint response and propose a design improvement.

ENGINEERING NOTES

  • Compared command response times using Python and identified rotate_joint as the slowest operation.
  • Tested an optimization in simulation and documented the expected response-time improvement.
  • Proposed sensor-alignment checks and joint reinforcement, and identified stress testing as a prerequisite before any rollout.
Simulation note

Educational job simulation hosted by Forage using a Johnson & Johnson MedTech scenario. This was not employment with Johnson & Johnson MedTech.
