Omokai - Mission PipelineProject imagery

THE BUILD

A spoken instruction becomes a structured mission through an LLM, passes a deterministic safety validator, then runs as a Nav2 task in Gazebo.

ENGINEERING NOTES

  • Kept LLM output untrusted: schema checks and safety bounds run before commands reach Nav2.
  • Used Groq (llama3-8b-8192) for consistent response times in the pipeline.
  • Traced a Nav2 activation hang to a slam_toolbox lifecycle dependency and fixed the cause instead of masking it with retries.
